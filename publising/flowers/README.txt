# Autumn Flowers Project

This project contains a small DITA documentation set about flower gardening, with a focus on autumn flowers and basic garden care.

## Overview

The documentation introduces flower gardening fundamentals, explains care and preparation practices, and provides seasonal information about flowers that bloom in autumn.

## Contents

The project currently includes:

- **Introduction** – an overview of flower gardening and how gardens can be planned by season, color, shape, and climate.
- **Care and Preparation** – guidance on feeding plants, controlling pests and weeds, and maintaining healthy soil conditions.
- **Pruning** – a task topic related to flower garden maintenance.
- **Garden Preparation** – a task topic covering preparation work for successful planting.
- **Flowers by Season** – seasonal organization of flower-related content.
- **Autumn Flowers** – a concept topic describing autumn as a season and listing flowers that bloom during this period.
- **Flower topics** – detailed topics for flowers such as Chrysanthemum and Salvia.
- **Copyright** – project copyright information.

## Structure

The main DITA map for this project is `autumn_flowers.ditamap`. It organizes the content into introductory, care, seasonal, and flower-specific topics.

## Purpose

This project appears to serve as a sample or starter documentation set for gardening content in DITA, demonstrating topic-based authoring with concepts, tasks, and reference-style information.

## Notes

- The content focuses on flower gardening and autumn-blooming flowers.
- The project includes both general gardening guidance and specific flower examples.
- Some topics may still be works in progress or intended for demonstration purposes.
